# 跨境数据合规（crossborder-data-compliance）出厂说明书 · 中文

> 版本 v2.0.0 · 2026-10-19 · 本安全智能体 P0 契约层

## 一、功能说明

跨境数据合规技能包是**出海前的合规闸门**，在数据跨境传输或海外功能上线前，自动完成合规校验，确保数据存储、传输符合目标地区法律法规。

核心能力：
- **三层校验**：目标地区法规 → 数据分类 → 传输链路
- **法规库版本化**：每条地区记录含法规版本号 / 生效日期 / 依据条目，校验结论可回溯到具体版本
- **数据分类引擎**：自动识别身份证件 / 生物识别 / 支付信息 / 账号凭据（敏感）→ 个人信息 → 普通业务
- **跨境收费/支付/税务专项校验**：支付通道 / 资金结算 / 税务登记
- **双通道接口**：语音 + 点击（提交校验 / 人工放行 / 查询 / 导出）
- **人工终审**：AI 只校验，放行须人工确认并留痕
- **撤销保护**：报告删除可撤销恢复
- **审计汇入**：16 列契约事件汇入操作日志审计

## 二、使用方式

### 命令行（无 UI 依赖）
```bash
# 三层校验
python crossborder_check.py --region <地区> --data-class <personal|business|sensitive> \
    --links 存储,加密,收费,支付,税务 [--override <放行原因>]

# 自动分类（用传输数据文本替代 --data-class）
python crossborder_check.py --region <地区> --content "<传输数据文本>" \
    --links 存储,加密,收费,支付,税务

# 子命令
python crossborder_check.py submit   --region <地区> --data-class <类> --links <链路>
python crossborder_check.py release  --region <地区> --reason "<放行原因>"
python crossborder_check.py classify --content "<传输数据文本>"
python crossborder_check.py charge-check --region <地区> --charge 支付通道,资金结算,税务登记
python crossborder_check.py register-region --name <地区> --tier <se-asia|english> --version <版本> --effective <日期>
python crossborder_check.py query    --result PASS --region <地区> --limit 20
python crossborder_check.py export   --format md|json|csv
python crossborder_check.py report                      # 中英双语分组报告
python crossborder_check.py clean --file <文件>          # 安全删除（可撤销）
python crossborder_check.py undo --list | --restore <id>
python crossborder_check.py --selftest                  # 自检（24 用例）
```

### 语音指令
- "出海检查 <地区> <数据>" → 发起三层校验
- "放行跨境 <地区> <原因>" → 人工放行（原因留痕）

### 点击入口
出海中心 → 跨境数据合规 → 发起校验 / 查看校验记录

## 三、安全边界

1. **未登记地区不放行**：目标地区不在两档市场内（或未登记）→ 拦截（CRIT）。
2. **数据分类先行**：传输前必须标注数据分类；**敏感数据零跨境**——命中身份证件 / 生物识别 / 支付 / 凭据 → 风险提示，未经合规评估 + 人工确认不放行。
3. **链路完整性**：存储位置 + 传输加密 + 跨境收费 / 支付 / 税务，缺任一必需项 → 拦截（CRIT）；传输加密未配置视为 CRIT。
4. **人工终审**：AI 只做校验，不自主定稿；放行须人工确认（human_decision=override + 原因留痕）。
5. **密钥红线**：API Key / 支付密钥只有管理员可查填；AI 不得打开、读取、扫描任何密钥文件与云端密钥配置。
6. **不动核心数据**：不修改任何业务数据库；校验事件只追加、不改不删（撤销除外）。
7. **不后台作业**：无无人值守后台任务与定时自动部署。
8. **敏感值零落盘**：分类只输出分类结果与依据条目，0 敏感数据值；报告全量 0 敏感值。

## 四、合规声明

- 本工具依据目标地区**现行**数据保护法规进行校验，以规则库登记的法规版本为依据，不预判"大概率没事"。
- 拦截 = 暂不推进上线 / 传输，**不删除数据**；处置走人工终审。
- 本工具提供的是**合规工程化校验**，不构成法律意见；具体地区的法律适用请咨询当地专业法务。
- 法规库版本可复算：任一校验结论均可回溯到具体法规版本号与生效日期。
- 敏感数据跨境须经合规评估并由人工确认后放行，默认零跨境。
- 数据分类仅输出类别与依据，**任何敏感数据值均不写入日志与报告**。
